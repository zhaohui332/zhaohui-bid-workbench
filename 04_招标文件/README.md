# 招标文件投放区

每次拿到新的招标文件，直接把它拖进这个文件夹即可，也可以带着附件一起发到 Codex 对话里。

建议按下面的方式命名，便于 Codex 判断哪份是最新有效版本：

```text
项目名称_招标文件_2026-09-04.pdf
项目名称_补遗01_2026-09-10.pdf
```

如果同一项目有正式招标文件、澄清、补遗，Codex 会全部读取，并以最新补遗和正文共同口径为准。发布过的不同版本不要删除也无妨，只要文件名里时间清楚；若分不清，Codex 会先按最新文件处理，并在生成说明里写明采用了哪份。

目录里还可以放：技术规格书、图纸、采购清单、评标办法、合同条款等附件。它们都属于招标文件的一部分。
