# 江苏兆辉防腐科技标书工作台

这个目录会慢慢长成你的“投标大脑”：把你公司的真实资料、历史标书、常用套话都放进来。以后拿到新的招标文件，Codex 就会先翻你的资料库和历史标书，再按你的习惯起草技术标和商务标。

## 第一次使用，做这三件事

1. 把公司真实资料填进 [02_企业档案](02_企业档案/README.md)，至少填企业基础信息。
2. 把之前做过的完整标书拖进 [01_历史标书](01_历史标书/README.md)，一个项目一个文件夹，不用整理格式，原样丢进去即可。
3. 有产品画册、技术协议、参数表、检测报告、资质证书、业绩合同，也分别放进去。

## 以后每次拿到招标文件

1. 把招标文件（含补遗）拖进 [04_招标文件](04_招标文件/README.md)。
2. 在本目录对 Codex 说一句话，例如：**“按 04_招标文件 里最新这份招标文件，结合我的历史标书和企业档案，帮我生成技术标和商务标。”**
3. 成品会出现在 [05_新建标书](05_新建标书/README.md)，Codex 会把每版写成可编辑的 Word。

## 网页工作台

这个目录还集成了一个本地网页版工作台，可以浏览资料、上传文件、打开模板和核对清单：

```text
http://127.0.0.1:8317
```

服务已经在当前任务中启动。以后如果服务停了，双击目录里的 `启动标书工作台.command`，或告诉 Codex“启动标书工作台”。请用上面的网址打开，不要直接双击 `index.html`，否则网页无法读取本地资料。

## 投喂越多，效果越好

- 每次中标或废标后，把结果告诉 Codex，它会把自己的经验写进 [06_投标记录/经验库.md](06_投标记录/经验库.md)。
- 每次你改动生成稿，Codex 会记下你喜欢的目录、措辞和格式。
- 新招标文件放入后，Codex 会优先读你最近的成功标书，而不是凭空发挥。

投喂历史标书后，Codex 会自动分析并把总结放进 [06_投标记录/历史标书分析](06_投标记录/历史标书分析/README.md)。分析进度可以在 [分析进度.md](06_投标记录/分析进度.md) 查看。

## 安全说明

你的文件只保存在这台电脑的这个文件夹里。模型不会拿你的标书去训练，每次生成都是现场查阅你投喂的资料；删掉文件后，Codex 以后就不会再读到它。涉及报价、证书、业绩时，请以真实原件为准，Codex 不会替你编造。
