# 交付前核对清单

Codex 生成初稿后逐项自检；用户在盖章前也要按此清单再审一遍。

## 完整性

- [ ] 采购清单里的每项设备都有对应商务报价和技术响应
- [ ] 招标文件要求的“投标文件组成”目录全部覆盖
- [ ] 法定代表人或授权人、盖章、签字位置齐全
- [ ] 保证金、业绩、资质等按招标文件要求放入

## 一致性

- [ ] 开标一览表总价与分项报价合计一致
- [ ] 报价表数量、单位与采购清单一致
- [ ] 投标函交期、质保与技术标、商务承诺一致
- [ ] 封面项目名称、招标编号与招标文件一致
- [ ] 企业名称、信用代码、印章名称一致

## 真实性

- [ ] 所有证书编号、业绩、注册信息都有原件可查
- [ ] 技术参数与公司产品资料/样本一致
- [ ] 没有【待补充】被误当作成稿内容
- [ ] 没有把历史项目的业主/项目名称串到本项目

## 格式

- [ ] 目录页码正确
- [ ] Word 排版可读、表格不溢出、字体统一
- [ ] 是否需要 PDF/电子投标系统转换及封面页眉页脚

## 风险复核

- [ ] 偏离表如实反映差异
- [ ] 不满足项已提前告知用户，而不是在技术标里含糊带过
- [ ] 投标截止时间、开标地点、加密/密封要求已提醒
