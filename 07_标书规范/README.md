# 标书规范

这个目录保存“通用目录、拆解方法、核对清单”，让 Codex 每次生成时保持同一套专业标准。

`模板/` 下有两份可直接打开、编辑的 Word 骨架模板：

- `商务标骨架模板.docx`：投标函、报价表、资格文件、偏离表、服务承诺等章节。
- `技术标骨架模板.docx`：技术响应、产品说明、工艺质量、供货进度、售后服务等章节。

Codex 后续生成正式标书时会按这些骨架和招标文件组织内容；你也可以先用模板手动改。

使用顺序：

1. 先按 `需求拆解表.md` 把招标文件读透。
2. 参考 `商务标通用目录.md` 和 `技术标通用目录.md` 组织初稿。
3. 交付前按 `交付核对清单.md` 逐项检查。

招标文件如有特殊目录或格式要求，以招标文件为准，优先于这里的通用目录。
