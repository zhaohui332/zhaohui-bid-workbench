# 历史标书投喂区

把你做过、觉得写得好（或吃过亏）的完整标书放进来。一个项目放一个子文件夹，例如：

```text
01_历史标书/
  某化工厂硫酸储罐项目/
    技术标.docx
    商务标.docx
  某电子厂废酸储罐项目/
    技术标.docx
    商务标.docx
```

没有技术标/商务标的名称也没关系，Codex 会自己读。文件名如果方便，可以写成“项目名_年月_技术标.docx”，方便知道哪个是最新风格。

历史标书不追求数量堆满，最好按质量挑：结构完整、格式规范、成功中标的优先。每次生成新标书前，Codex 会自动检索这些文件，学习你的章节顺序、表达习惯、表格口径和常用措辞。
